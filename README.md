В виду того, что необходимо скачать только 1 библиотеку сторонний пакетный менеджер или файл requriments.txt не использовал

### Запуск
Установка библиотеки

```bash
pip install requests
```

Запуск скрипта
```bash
python solution.pyk
```

Далее необходимо будет ввест url-адрес и дождаться вывода работы программы
Скорость выводится в байтах в секунду
